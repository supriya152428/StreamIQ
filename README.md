# 🎬 StreamIQ — Netflix Analytics

An end-to-end Data Analytics project analyzing Netflix Movies and TV Shows to uncover insights about content, genres, ratings, countries, and catalog growth.

## 🛠️ Tech Stack

- Excel
- Python / Pandas / NumPy
- PostgreSQL / SQL
- Power BI

## 🔄 Workflow

**Excel → Python/Pandas → PostgreSQL/SQL → Power BI**

- Cleaned and transformed Netflix data
- Created normalized genre and country datasets
- Performed SQL analysis using JOINs, CTEs, subqueries, window functions, and aggregations
- Built interactive Power BI dashboards

## 📊 Dashboard

**Overview | Content | Global | Trends**

The dashboard covers:
- Movies vs TV Shows
- Top Genres
- Ratings
- Content-producing Countries
- Geographic Distribution
- Catalog Growth & Trends
