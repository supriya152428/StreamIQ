🎬 StreamIQ — Netflix Content Strategy & Catalog Intelligence
StreamIQ is an end-to-end Data Analytics project that analyzes the Netflix Movies and TV Shows catalog to uncover insights about content types, genres, ratings, countries, and catalog growth over time.

📌 Project Overview
The project follows a complete analytics workflow:

Excel → Python/Pandas → PostgreSQL/SQL → Power BI

The goal was to transform raw Netflix catalog data into meaningful business insights through data cleaning, ETL, SQL analysis, and interactive dashboards.

🛠️ Tech Stack
Excel — Initial data cleaning and exploration
Python — ETL and data transformation
Pandas / NumPy — Data manipulation and feature engineering
PostgreSQL — Data storage and analysis
SQL — Data analysis and business queries
Power BI — Interactive dashboard and visualization
DAX — Power BI measures
Git & GitHub — Version control
🔄 Project Workflow
Raw Netflix Dataset ↓ Excel Cleaning & Exploration ↓ Python / Pandas ETL ↓ Data Normalization ↓ PostgreSQL ↓ SQL Analysis ↓ Power BI + DAX ↓ Interactive Dashboard
